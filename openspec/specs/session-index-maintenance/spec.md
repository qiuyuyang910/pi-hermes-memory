# session-index-maintenance Specification

## Purpose

定义历史查询索引中的临时回顾会话清理边界，使不同操作系统产生的临时提示附件能够被识别，同时保留真实文件会话、普通无文件会话及当前角色实例之间的索引隔离。

## Requirements

### Requirement: 临时回顾会话清理不依赖操作系统目录

系统 SHALL 识别用户消息的临时回顾提示附件包装，在会话没有关联文件记录时清理该会话及其消息。识别 SHALL 不限定 Linux `/tmp` 前缀，不要求提示消息是首条消息或会话只有一条消息。

#### Scenario: Windows 或 macOS 的临时回顾会话

- **WHEN** 无文件会话中的用户消息携带临时回顾提示附件，附件路径位于 Windows 或 macOS 临时目录
- **THEN** 系统清理该会话及其消息，与 Linux 路径具有相同处理结果

#### Scenario: 临时回顾会话已经索引回复

- **WHEN** 无文件会话同时包含临时提示用户消息和助手回复，或提示用户消息不是最早消息
- **THEN** 系统仍按提示附件标识清理该会话

### Requirement: 清理保留真实会话和所属实例边界

系统 SHALL 保留具有文件记录的会话，以及没有临时提示用户附件标识的无文件会话；正文只提及临时目录标识不构成清理条件。清理 SHALL 仅作用于当前实例的历史索引。

#### Scenario: 文件会话引用临时提示附件

- **WHEN** 会话具有文件记录，即使其消息包含临时提示附件
- **THEN** 系统保留该会话、消息和文件记录

#### Scenario: 普通消息引用临时目录名称

- **WHEN** 无文件会话的消息只引用临时目录标识，未形成符合条件的用户提示附件包装
- **THEN** 系统保留该会话

#### Scenario: 清理一个角色的索引

- **WHEN** 某角色实例执行临时回顾会话清理
- **THEN** 其他角色和普通模式的历史索引不受影响
