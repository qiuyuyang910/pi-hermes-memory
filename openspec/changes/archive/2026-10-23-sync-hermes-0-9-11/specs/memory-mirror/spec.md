# Spec Delta

## Purpose

定义 Markdown 记忆进入查询镜像时的内容和归属规则，使多行条目保留正确日期与项目元数据，同时让记忆查询保持所属实例和作用域边界，避免元数据注释被当作正文检索。

## ADDED Requirements

### Requirement: 多行条目正确分离正文和元数据

系统 SHALL 对包含换行的合法记忆条目解析末尾元数据注释，保留正文、创建日期和最后引用日期，并将注释从可检索正文中移除；现有单行条目与无合法元数据条目的处理语义 SHALL 保留。

#### Scenario: 多行正文带有日期元数据

- **WHEN** Markdown 条目正文包含换行，末尾具有合法的创建日期和最后引用日期注释
- **THEN** 查询镜像保存完整多行正文和注释中的日期，可检索正文不包含元数据注释

### Requirement: 多行项目失败记忆保留项目归属

系统 SHALL 从多行条目的合法 `project64` 元数据恢复项目归属；项目失败记忆 SHALL 保留对应项目，不能因正文含换行而进入全局失败记忆范围。

#### Scenario: 同步多行项目失败记忆

- **WHEN** 一个失败记忆条目具有多行正文和合法的项目元数据
- **THEN** 按对应项目查询可以检索该条目，其项目归属不变成空值

### Requirement: 作用域内容查找保持隔离

系统 SHALL 在记忆同步的内容查找中保留目标、项目和类别条件，不将其他作用域的相同正文条目作为当前条目的匹配结果。

#### Scenario: 不同项目具有相同正文

- **WHEN** 两个项目在相同目标和类别下各自保存相同正文
- **THEN** 同步其中一个项目时，仅匹配该项目的条目，不改变另一项目的记忆
